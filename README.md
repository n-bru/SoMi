# SoMi

Persönliche Web-App für Noten und Beobachtungen in Mathe und Sport (Gesamtschule NRW). Läuft offline auf dem iPad, speichert nur auf dem Gerät, nur mit Kürzeln.

- Beta: https://n-bru.github.io/SoMi/beta/
- Quelldatei: `quelle/somi.html`
- Regeln für die Weiterentwicklung: `CLAUDE.md`
- Stand und offene Punkte: `docs/uebergabe.md`

Der Technik-Kern stammt aus [Pfad](https://github.com/hbg-pfad/pfad). Das Repo enthält nur Code, keine Daten.
